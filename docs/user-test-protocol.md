## 对象与规模

- 3–5 名非本项目开发者，最好包含 1 名对石油行业不熟悉的用户；
- 每人独立操作，主试只读任务、不提示；
- 桌面 1440×900 或 1920×1080，Chrome/Edge；
- 全程录屏或至少记录关键时间点。

## 任务 1：找到地下储层并说明井筒与井口的关系

1. 打开 `sandbox.html`，不点“沉浸导览”；
2. 请用户指出“油藏在哪里”，再指出它如何到达地面；
3. 追问：井筒和井口分别在哪、是什么关系。

记录：是否找到、用时、是否把“油湖”当成储层、是否把井口当成井筒。

## 任务 2：解释三相分离器为什么分三路

1. 进入「地面处理」或点击三相分离器；
2. 请用户说明气、油、水为什么走不同出口；
3. 追问：如果出口接错会怎样。

记录：是否提到密度/相态、是否误认为颜色代表真实物料、能否说出三路去向。

## 任务 3：讲出原油到终端产品的基本过程

1. 从「流程总览」开始，允许使用设备列表、关卡和知识页；
2. 请用户按顺序讲一遍：开采 → 处理 → 储运 → 炼化 → 产品；
3. 追问：常压塔出来的是不是成品汽油；塑料是否一定来自石油。

记录：顺序是否正确、是否把馏分当成品油、是否把塑料绝对化为石油来源、卡在哪一环。
