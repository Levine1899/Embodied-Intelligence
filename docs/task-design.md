# Phase 02 · 任务探索系统设计

日期：2026-11-22
主任务名：**《批次 YJ-001：把一批原油送到城市》**
用户角色：能源调度见习员（不是“玩家”，不设积分/排行榜）
教学边界：批次是教学复合体，不是一滴油；不编造压力、温度、流量、产能、收率或排放数据。

## 1. 任务总览

```text
接单 → 地下找油 → 井口举升 → 油气水分离 → 储运选择 → 炼化分馏 → 城市交付 → 复盘
  T0      T1          T2           T3           T4          T5          T6        T7
```

- 主任务贯穿六个视觉区、五个既有 stage；每段对应一个现有五关，不新增“答题积分”。
- 五个子任务全部完成才可“完成交付”；允许跳段探索，但交付前必须补齐缺失章。
- 每个子任务有 3 级提示；提示不直接给答案，逐级增加约束。
- 误操作不丢失进度；状态写入 `session.batch` / `session.task`，退出再进可继续。
- 至少两条分支有不同视觉结果：气出口（回收/火炬）、储罐类型（浮顶/固定顶）、炼化重点（燃料/材料）。

## 2. 子任务定义

### T0 接单：批次牌

| 项 | 内容 |
|---|---|
| 背景/角色 | 调度中心收到批次 YJ-001，需要见习员确认接单 |
| 目标 | 找到并点击场景中的批次牌，确认批次号 |
| 线索 | 井口旁的黄铜牌；底部“待接单”；设备列表中的“批次 YJ-001”入口 |
| 用户操作 | 点击批次牌 / 按 Enter |
| 场景变化 | 批次牌被提起、盖“接单”章；路线从井口向地面延伸 1 段 |
| 成功条件 | `batch.node='wellhead'`，`stamps=['accept']` |
| 失败反馈 | 点击空白：底部提示“先找到那枚批次牌”，不扣分 |
| 提示 | L1“它在井口旁边” → L2“找黄铜反光的牌子” → L3 高亮 3 秒 |
| 重置 | 无需；可重新点击 |
| 复盘 | 一句“这批原油从地下储层来，接下来先到井口” |

### T1 地下：让油动起来

| 项 | 内容 |
|---|---|
| 对应关卡 | l1 地下开采 |
| 目标 | 调节“压力差示意”，让油从储层向井底运移，并读出边界 |
| 线索 | 岩芯孔隙里的油点、井筒、压力滑块；底部“油还没动”提示 |
| 用户操作 | 拖动滑块 0–100 |
| 场景变化 | 油向井底粒子加速；批次牌向井筒移动；≥60 出现“正在运移”；≥90 完成 |
| 成功条件 | 压力 ≥90（教学完成阈值），且用户看到至少一次流动变化 |
| 失败/边界 | <30 提示“孔隙里的油还没动”；接近 100 提示“这是示意，不代表真实井底压力/采收率” |
| 提示 | L1“看看滑块和油点” → L2“压力差是驱动力” → L3 推荐 60–90 区间，不直接给 90 |
| 重置 | “重来”恢复 0；只重置本段 |
| 复盘 | 压差驱动 + 储层/开发条件限制；采收率不是滑块能算出的 |

### T2 井口：接入地面

| 项 | 内容 |
|---|---|
| 对应关卡 | l1 出口 / 地面入口 |
| 目标 | 把批次从井筒接到井口，再送入集输 |
| 线索 | 井口采油树、阀组、管线方向；设备卡“打开阀组” |
| 用户操作 | 点阀组 / “接入集输” |
| 场景变化 | 井口阀组微动；批次牌沿管线进入分离器；章“已举升” |
| 成功条件 | `batch.node='separator'` |
| 失败反馈 | 未接单就开阀：提示“先接单再开阀”，不扣进度 |
| 提示 | L1“井口有阀组” → L2“先接单，再开阀” → L3 高亮阀组 |
| 重置 | 关闭阀组，回到井口 |
| 复盘 | 井筒连接储层与地面；井口控制流体进入集输 |

### T3 分离：三路去向（含分支）

| 项 | 内容 |
|---|---|
| 对应关卡 | l2 地面处理 |
| 目标 | 剖开分离器，认清气/油/水三出口；为气选择去向，把油送入储运 |
| 线索 | 分离器三个出口、颜色/文字标签、设备卡“剖开” |
| 用户操作 | 点“剖开”→ 观察内部挡板/堰板 → 选气出口“回收/火炬”→ 点油罐 |
| 场景变化 | 切面打开；气/油/水三路流动；气回收进入燃料气管，火炬则出现受控火焰；油进入储罐 |
| 分支 A 回收 | 气进入燃料气管网，火焰不出现；提示“回收利用，减少放空”；章“已分离” |
| 分支 B 火炬 | 火炬点燃（受控、非事故），提示“安全泄放路径，不等于日常放空”；章“已分离” |
| 成功条件 | 气有明确去向 + 油入油罐 + 水入水处理；三者都完成 |
| 失败反馈 | 气送油罐：红色回流 + “气不能进常压油罐”，退回选择；油送水罐同理 |
| 提示 | L1“三个出口分别是什么” → L2“气体轻、油水按密度” → L3 高亮正确出口，但仍让用户点 |
| 重置 | 合上分离器，清空本段选择，保留已得章 |
| 复盘 | 分离按相态/密度，不是过滤；火炬是安全路径，回收优先；不估算排放量 |

### T4 储运：选罐型（含分支）

| 项 | 内容 |
|---|---|
| 对应关卡 | l3 储运 |
| 目标 | 为这批原油选择储罐，并解释油气空间差异 |
| 线索 | 固定顶罐/外浮顶罐、液位滑块、浮盘、防火堤 |
| 用户操作 | 选择罐型 → 拖液位 0–100 → 观察浮盘/油气空间 → 确认 |
| 场景变化 | 浮顶罐浮盘随液位；固定顶罐油气空间随液位变化；批次牌进入所选罐 |
| 分支 A 外浮顶 | 浮盘贴液面，油气空间小；提示“适合易挥发油品，但损耗仍受密封/附件影响” |
| 分支 B 固定顶 | 油气空间大；提示“需要呼吸阀/油气处理；不是绝对不能用的罐” |
| 成功条件 | 选罐 + 至少一次液位变化 + 确认；两种都可成功，但记录选择与解释 |
| 失败反馈 | 不选罐直接确认：提示“先选一个罐”；液位拖到极端不报错，只提示边界 |
| 提示 | L1“两个罐顶不一样” → L2“浮盘跟着液面” → L3 高亮浮盘与油气空间 |
| 重置 | 液位回 2%，罐选择清空，保留章 |
| 复盘 | 浮顶减少油气空间，但损耗受密封/附件/维护影响；不换算真实排放量 |

### T5 炼化：分馏与路线（含分支）

| 项 | 内容 |
|---|---|
| 对应关卡 | l4 炼化 |
| 目标 | 把批次送入常压塔，识别五种馏分，并选择加工重点 |
| 线索 | 加热炉、常压塔、侧线、塔板、馏分卡 |
| 用户操作 | 点“进塔”→ 半剖/全剖 → 把五种馏分放到塔位 → 选“交通燃料优先/化工原料优先” |
| 场景变化 | 半剖见塔板；全剖见塔板/降液管/侧线/汽液粒子；侧线高亮；下游管线方向变化 |
| 分支 A 燃料优先 | 侧线流向燃料/调和方向；提示“汽油/柴油/航空煤油仍需调和与精制” |
| 分支 B 材料优先 | 石脑油等流向化工原料方向；提示“化工原料路线取决于装置配置” |
| 成功条件 | 五种馏分全对 + 选择一个重点 + 批次进入产品区 |
| 失败反馈 | 馏分放错：弹回 + 一句“更轻的馏分在更上面”；不扣分 |
| 提示 | L1“沸点低的往上” → L2“塔顶最轻，塔底最重” → L3 高亮正确层，但仍让用户放 |
| 重置 | 清空馏分放置，回到进塔前；保留罐型选择 |
| 复盘 | 馏分≠成品油；后续裂化/重整/加氢/调和；两种重点都有效，不编造收率 |

### T6 城市：交付与应用（含分支）

| 项 | 内容 |
|---|---|
| 对应关卡 | l5 产品去向 |
| 目标 | 把馏分/产品匹配到城市应用，完成交付 |
| 线索 | 城市街区、加油站、材料台、产品卡 |
| 用户操作 | 把 5 个馏分/产品拖到对应应用 → 选“燃料优先/材料优先” → 完成交付 |
| 场景变化 | 正确配对盖章；错误退回；城市灯光/材料权重变化；批次牌盖“交付”章 |
| 分支 | 燃料优先：城市交通/加油站权重更高；材料优先：塑料/纤维/沥青权重更高；都不代表真实产量 |
| 成功条件 | 5 个配对正确 + 一次重点选择 + 批次到达城市 |
| 失败反馈 | 塑料→“塑料只能来自石油”：提示“也可能来自天然气/煤基/生物基”；不扣分 |
| 提示 | L1“看产品卡上的用途” → L2“燃料/材料/路面分三类” → L3 高亮一个正确配对 |
| 重置 | 清空配对，保留炼化选择 |
| 复盘 | 同一批原油可走不同重点；产品路线不是唯一；塑料原料不绝对 |

### T7 交付复盘

| 项 | 内容 |
|---|---|
| 触发 | 五段章齐全后点“完成交付” |
| 内容 | 路线图（六区）、5 枚知识章、3 个选择（气/罐/重点）、用时、AI 追问入口 |
| 操作 | “再走一次”（重置批次，不清知识）/“自由探索”/“看塔剖面”/“生成材料” |
| 知识总结 | 储层→井筒→分离→储运→分馏→产品；每段一句边界 |
| 下一步 | 自由探索未看设备；塔页看内部；AI 问“为什么”；生成作品（可选） |

## 3. 分级提示规则

| 级别 | 触发 | 内容 | 是否直接给答案 |
|---|---|---|---|
| L1 方向 | 首次 15s 无操作/错 1 次 | “先看看当前设备/滑块” | 否 |
| L2 约束 | 错 2 次/30s | “气比油轻；浮盘贴液面；沸点低的在上” | 否 |
| L3 定位 | 错 3 次/45s | 高亮正确对象/区域 3s | 不自动执行，仍由用户点 |

- 提示使用次数记录在 `task.hintLevel`，复盘显示“用过 2 次提示”，不扣分。
- 提示不能代替操作；L3 也不自动完成。
- 任何提示不出现编造数值；只出现教学阈值（如压力 90% 完成），并标注示意。

## 4. 失败、重试与状态

- 失败是**可解释的分支/边界**，不是“游戏结束”：
  - 气进油罐 → 回流 + 原因；
  - 馏分放错 → 弹回 + 原理；
  - 罐型选固定顶 → 仍成功，但记录不同解释；
  - 未接单开阀 → 提示顺序。
- 每段有“重来本段”；整单有“重置批次”（清批次与选择，保留知识浏览记录）。
- 退出/刷新：`sessionStorage` 保存批次节点、章、选择；不保存任何 API Key/个人数据。
- 完成度：`stamps` 五枚 + T0 接单 = 六章；缺章时“完成交付”提示“还差哪一段”，不强制顺序。

## 5. 分支的教学正确性

| 分支 | 选项 | 视觉差异 | 科学表述 | 禁止 |
|---|---|---|---|---|
| 气去向 | 回收 / 火炬 | 燃料气管网 vs 受控火焰 | 回收优先；火炬是安全泄放；不估算排放 | 不说“火炬=日常放空” |
| 罐型 | 外浮顶 / 固定顶 | 浮盘贴液面 vs 油气空间大 | 浮顶减少油气空间；损耗仍受密封/附件影响 | 不换算真实排放量 |
| 炼化重点 | 燃料 / 材料 | 侧线流向不同；城市权重不同 | 两种路线都有效；馏分≠成品油；后续加工不同 | 不编造收率/比例 |
| 产品原料 | 石油 / 非石油 | 正确/错误配对 | 塑料可能来自天然气/煤基/生物基 | 不说“塑料一定来自石油” |

## 6. 与现有五关的映射

| 任务 | 现有实现 | 复用方式 | 需补 |
|---|---|---|---|
| T1 | l1 滑块/完成阈值 | 直接复用 interaction 与粒子 | 接单/批次状态、提示层 |
| T2 | l1 井口/设备卡 | 复用井口 objectId | 阀组动作、进入分离器 |
| T3 | l2 出口/罐 | 复用三出口与错误反馈 | 剖切内部、气回收/火炬分支 |
| T4 | l3 液位/双罐 | 复用浮盘/油气空间 | 选罐确认、分支解释 |
| T5 | l4 五馏分 | 复用五种馏分与错误反馈 | 全剖内部、燃料/材料分支 |
| T6 | l5 产品选择 | 复用 6 件石油路线产品/4 干扰 | 拖拽配对、城市交付 |

## 7. 验收标准（阶段 07/09）

- 用户能不看说明完成 T0，并在 3 分钟内完成 T1；
- 五段中至少三条分支可被用户主动选择，且视觉/文案不同；
- 失败不阻断，提示三级且不泄题；
- 退出再进能继续；重置能回到本段初始；
- 复盘列出路线、选择、知识章，不显示积分/排名；
- 无 API 时任务仍可完成，AI 显示本地知识/不可用提示；
- 所有任务不出现编造工程数值。
