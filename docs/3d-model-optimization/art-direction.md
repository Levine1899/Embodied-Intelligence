# Art Direction 规范（V1.1 · Phase 10）

> 适用范围：总览、L1–L5 关卡、微观测视。**不改变**设备结构与工艺表达，只统一"怎么看"。

## 1. 成像基线
| 项 | 口径 | 依据 |
|---|---|---|
| 色彩空间 | 渲染线性 → sRGB 输出，`ColorManagement` 开启 | Three r180 默认 |
| Tone mapping | ACES Filmic | 既有实现（immersion.js） |
| 曝光 | **1.15**（原 1.2） | Phase 9 实测浅色岩层过曝，下调 0.05 |
| DPR 上限 | 2（移动端按需降到 1.5） | 既有 + Phase 10 守卫 |
| 抗锯齿 | MSAA（`antialias: true`） | 既有 |
| 背景 | 深色工业底色，不用纯黑 | 与 HUD 对比度 |

## 2. 光照
- 主光 1 盏（定向）+ 半球光 1 + 环境光 1；**不再新增**点光源。
- 阴影只对"教学关键结构"开启（井口、储层、主设备）；远景/管线组不投影。
- 环境光强度上限 0.6：超过会把地层压成一片米白（Phase 9 已踩过）。

## 3. 材质分层（四档）
1. **金属结构**：涂装碳钢 / 不锈钢 / 镀锌钢 —— 低粗糙度、有金属度，靠高光辨认。
2. **土建**：混凝土 —— 高粗糙、零金属度，不抢视觉焦点。
3. **地质**：砂岩 / 泥岩 / 储层 —— 零金属度、高粗糙；**颜色只表达岩性差异，不表达数值**。
4. **流体**：油 / 水 / 气 —— 半透明，统一 `depthWrite:false`、按 `renderOrder` 分层，避免互相穿插闪烁。

## 4. 透明与叠加
| 层 | renderOrder | depthWrite |
|---|---|---|
| 流体（油/水/气） | 6 | false |
| 孔隙/微观叠加 | 7 | false |
| UI 型叠加标记 | 8 | false |

## 5. 视觉纪律（禁止项）
- 不为了"好看"改变设备层级、工艺连接或物流方向。
- 不用高饱和颜色区分"好/坏"，避免价值判断。
- 不把教学示意材质（油/气/水）说成真实流体参数。
- 任何全局材质替换必须附视觉回归截图，否则不许合入。
