# Phase 02 · Hero Asset 参考板与制作标准

日期：2026-11-22
原则：参考板用于**约束结构、比例、视角和语义节点**，不是最终模型；不得把参考图/渲染图当成交付资产。
所有资产必须区分：`可直接复用 / 需精修 / 必须新建 / 暂缺`，并明确责任阶段。

## 1. 统一交付清单（新建或实质性修改的 Hero）

| 项 | 要求 |
|---|---|
| 可编辑源 | `.blend`（Blender 4.5 LTS），保留建模历史、命名、材质 |
| 运行格式 | `.glb`（记录用）+ 现有管线可用的 `.obj/.mtl`；不强行引入新 loader |
| 尺度/轴向 | 米制，Y-up，原点在设备底部中心；导出前应用变换 |
| 语义节点 | 每个可交互部件有稳定名称/ID，写入 `.meta.json` 与运行时注册表 |
| 材质/贴图 | 基础色/粗糙度/金属度；贴图注明色彩空间（sRGB/Linear）、压缩、来源 |
| 授权 | 来源、作者、许可证、可商用范围；无授权不得标“可直接商用” |
| 检查视图 | 正面、侧面、斜 45°、局部/剖切；线框/法线可选 |
| 网页证据 | 真实浏览器加载、交互、截图/录屏；不拿 Blender 静帧代替 |

## 2. 资产 A：地下地质与井筒

### 参考板（自绘结构示意，非最终模型）

```
正面（南侧看向剖面）                     侧面（西侧）
┌──────────────────────────────┐        ┌──────────────────────┐
│ 地表 ─────────────────────── │        │ 地表 ─────────────── │
│ ① 覆盖层（砂/泥/砾）          │        │ 覆盖层               │
│ ② 盖层（致密泥岩）            │        │ 盖层                 │
│ ③ 储层（砂岩，油点）          │        │ 储层透镜体           │
│ ④ 底水层（水）                │        │ 底水                 │
│ ⑤ 井筒（套管+水泥环）         │        │ 井筒垂直             │
│ ⑥ 井口采油树（地表）          │        │ 井口                 │
└──────────────────────────────┘        └──────────────────────┘
        斜 45°（东南俯视）                       局部/剖切
   ┌──────────────────────┐              ┌──────────────────────┐
   │ 层理沿 X 方向展开     │              │ 井筒剖面：套管/水泥环 │
   │ 井筒从储层穿到井口    │              │ 射孔段/储层连接       │
   └──────────────────────┘              └──────────────────────┘
```

### 结构与比例

- 剖面体块：约 24×14×12m（教学尺度，**垂直方向夸张**，不是真实油藏深度）。
- 地层 6 层：表土、砂砾层、泥岩盖层、砂岩储层、底水层、基岩；层厚不等，层理可见。
- 井筒：垂直，套管 + 水泥环 + 射孔段；从储层顶部穿至井口。
- 井口：采油树、阀组、翼阀、压力表；与井筒同轴。
- 储层：透镜状，不是“油湖”；油点/孔隙在层内分布，底水在下。

### 语义节点

`geo_overburden`、`geo_caprock`、`geo_reservoir`、`geo_aquifer`、`geo_basement`、`geo_wellbore_casing`、`geo_wellbore_cement`、`geo_perforation`、`wellhead_tree`、`wellhead_wing_valve`、`wellhead_gauge`。

### 材质/灯光

- 层理用暖褐/灰绿/砂岩色差 + 颗粒噪声；储层用低饱和油点，不做发光油。
- 井筒旧钢/水泥灰；井口旧漆+锈；局部暖光从剖面开口进入。
- 禁止用一整块黑色切面 + 荧光油点。

### 制作/责任

| 项 | 内容 |
|---|---|
| 状态 | **必须新建**（当前只有程序化台阶） |
| 负责阶段 | **04 地下体验** |
| 来源/授权 | 项目自建；无第三方资产；完成后登记作者/许可证 |
| 参考来源 | 自绘结构示意 + 公开石油地质科普概念；不复制未授权图片 |
| 预算 | 15–25k 三角面；1 套材质组；≤8 draw calls |
| 网页验收 | 可从南侧看入；层理/储层/井筒/井口关系可读；井口与地面连接不穿模 |

## 3. 资产 B：三相分离器

### 参考板

```
正面（长轴）                                    端面（气出口侧）
┌──────────────────────────────────────┐        ┌──────────────┐
│  ◯气出口        ┌──挡板──┐           │        │   ◯ 气出口    │
│   │             │ 堰板   │   ◯油出口  │        │  壳体/封头    │
│  ═╪═════════════╪════════╪══════════ │        │  鞍座         │
│   │  进口 →     │ 油水界面│          │        │  水出口       │
│  ◯水出口        └────────┘           │        └──────────────┘
└──────────────────────────────────────┘
        斜 45°（进口侧）                          剖切（半剖）
   ┌──────────────────────┐              ┌──────────────────────┐
   │ 卧式壳体/鞍座/接管    │              │ 内部：进口挡板/堰板   │
   │ 三个出口朝上/侧/下    │              │ 气腔/油腔/水腔分界    │
   └──────────────────────┘              └──────────────────────┘
```

### 结构与比例

- 卧式圆筒，长:径 ≈ 3.2:1；两端椭圆封头；两个鞍座；底部支腿。
- 进口在一侧中部，气出口在顶部，油出口在侧上，水出口在底部。
- 内部：进口挡板/分配器、油水堰板、气液分离空间；可半剖/全剖。
- 仪表：压力表/液位计/阀轮；接口法兰明确。

### 语义节点

`sep_shell`、`sep_head_w`、`sep_head_e`、`sep_inlet`、`sep_gas_outlet`、`sep_oil_outlet`、`sep_water_outlet`、`sep_saddle_w`、`sep_saddle_e`、`sep_inlet_diverter`、`sep_weir`、`sep_level_gauge`、`sep_pressure_gauge`、`sep_valve_*`。

### 材质/灯光

- 旧白/浅灰涂装钢，焊缝/法兰/锈迹；仪表深色；油/气/水用低饱和色带 + 文字，不靠发光。
- 剖切面用深色截面 + 轻微高亮边线，避免“切开后一片黑”。

## 4. 资产 C：炼化装置群与常减压蒸馏塔

### 参考板

```
装置群（东北高地，斜 45°）                     常压塔正面
┌────────────────────────────────────┐        ┌──────────────┐
│      火炬                          │        │  ◯ 塔顶油气   │

│  烟囱 │      │      │   │      │   │        │  ├─ 塔板      │

│  │加│ │      └──┬───┘   └──┬───┘   │        │  ├─ 进料      │

│  │炉│ └─────────┴──────────┘        │        └──────────────┘
└────────────────────────────────────┘
        半剖                                      全剖
   ┌──────────────────────┐              ┌──────────────────────┐
   │ 半个壳体 + 塔板       │              │ 全壳隐藏：塔板/降液管 │
   │ 侧线抽出可见          │              │ 侧线/汽液粒子/进料    │
   └──────────────────────┘              └──────────────────────┘
```

### 结构与比例

- 装置群：常压塔（主塔，最高）、减压塔（约 0.6 倍高）、加热炉（约 0.35 倍高）、烟囱/火炬、管廊、空冷器/泵。
- 常压塔：塔板 12–16 层，进料在中下部，侧线 4 条，塔顶气相线，塔底渣油线。
- 塔体细节：平台、护栏、梯子、人孔、法兰、保温层；不要“光溜溜圆柱”。
- 全剖：外壳隐藏，塔板/降液管/侧线/汽液粒子全部可见；半剖只隐藏半壳。
- 减压塔：真空系统接口、塔底渣油线；不夸大“负压”视觉。

### 语义节点

`ref_atm_tower`、`ref_atm_shell`、`ref_atm_shell_half`、`ref_atm_trays`、`ref_atm_demister`、`ref_atm_side_*`、`ref_vac_tower`、`ref_vac_shell_half`、`ref_heater`、`ref_stack`、`ref_flare`、`ref_pipe_rack`、`ref_feed_line`、`ref_bottom_line`。

### 材质/灯光

- 旧钢/保温铝皮/锈；平台深灰；侧线用低饱和管色；火炬只在安全泄放时可见，不做常年大火。
- 逆光边缘光，少量蒸汽；不做霓虹描边。

## 6. 授权与来源规则

1. 现有五台 Hero 与塔由 `tools/` 脚本生成，属项目自建；仍需在资产目录补 `LICENSE/NOTICE` 或来源记录，写清作者、生成日期、可商用范围。
2. 不得把中国石油报配图、品牌 logo 作为模型贴图或参考板再分发；参考板使用自绘结构示意。
3. 若使用第三方贴图/HDRI/字体，必须记录许可证；无授权不得标“可直接商用”。
4. Blender 生成资产不得直接使用未授权插件/资产库；导出前清理外部链接。

## 7. 阶段门禁

- 阶段 04：地质/井筒 Hero 未达 → 地下体验不得 PASS；可交付占位但视觉验收 BLOCKED。
- 阶段 05：分离器无内部剖切/语义节点 → 处理体验不得 PASS。
- 阶段 06：塔全剖视觉差异不显著 → 炼化体验不得 PASS。
- 阶段 09：三类 Hero 的 `.blend`、授权、网页证据缺一不可；不得用程序化模型或 Blender 静帧冒充。
