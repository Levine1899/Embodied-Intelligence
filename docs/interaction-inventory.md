# Phase 01 · 现有交互清单与缺口

日期：2026-11-22
判定标准：**用户动作 → 场景状态变化 → 可观察结果 → 原理解释/反馈** 四项全部满足，才计为深度互动；hover、仅弹卡、仅镜头移动、无用户参与的自动播放不计。

## 3. 五个关卡（实测）

`tools/level-e2e.cjs` 在 headed Chrome 中逐关执行“进入 → 操作 → 退出”，五关全通过。

| 关卡 | 动作 | 状态变化 | 可观察反馈 | 教学边界 | 上下文写回 | 深度互动 |
|---|---|---|---|---|---|---|
| l1 地下开采 | 拖压力差滑块 0–100 | 油向井底流动粒子加速；≥90 完成 | 粒子速度、提示文案 | 文案明确“示意百分比”，不映射真实压力/采收率 | `adjust_pressure=50` | **是** |
| l2 地面处理 | 选出口，再点对应罐 | 选中出口；错误罐变红退回；正确后开常流 | 颜色/流向/回流 | 油/气/水三路；不伪造分离效率 | `choose_outlet=oil` | **是** |
| l3 储运 | 拖液位 0–100 | 固定顶罐油气空间变化；外浮顶盖随液面 | 两个罐的液位/空间对比 | 明确“不换算真实排放量” | `change_liquid_level=50` | **是** |
| l4 炼化 | 选五种馏分，放到塔位 | 馏分选中/吸附/错误反馈 | 塔位与馏分匹配 | 明确“馏分≠成品油”；五种含塔顶油气 | `choose_fraction=topgas` | **是** |
| l5 产品去向 | 勾选 10 件中的石油路线产品，确认 | 选中计数、正误反馈 | 选中态/结果 | 明确塑料可能来自天然气/煤基/生物基 | `select_product=汽油` | **是** |

> l5 的 6 件“石油路线产品”是汽油、柴油、航空煤油、沥青、塑料制品、石蜡；玻璃/棉花/水泥/食盐为干扰项。它仍是“挑出来”的选择任务，不是可追踪的原料→产品路线。

## 4. 塔页交互

| 动作 | 状态变化 | 可观察反馈 | 知识 | 缺口 |
|---|---|---|---|---|
| 点 5 个热点 | 相机定位到对应设备/区域，右侧说明切换 | 标签高亮、说明卡 | 塔板/侧线/减压/加热炉 | 热点点击不作为 AI 上下文 |
| 外观 / 半剖 / 全剖 | 整壳显隐、半剖壳显隐、粒子显隐 | 半剖可见塔板；全剖多少量汽液粒子 | 文字说明“灰青上升/琥珀下降” | 全剖与半剖像素差 0.29/255；内部结构没有真正展开 |
| 拖拽/滚轮 | 相机旋转/缩放 | 视角变化 | 无 | 无设备级操作实验 |
| 重置视角 | 相机回到预设 | 可见 | 无 | 无 |

塔页没有 `window.__sceneContext`，因此无法把“当前塔/热点/剖切状态”传给 AI，也没有跨页设备上下文。

## 5. AI 与创作闭环

| 入口 | 当前行为 | 无 API 时 | 问题 |
|---|---|---|---|
| 沙盘右栏“问一句” | 依赖 `ai.js` 插入 `.leadai` | — | **当前 `insertBefore` 异常，面板完全不挂载** |
| 设备卡“问 AI” | 找 `#leadai-q`，填问题并滚动 | — | 面板不存在，点击静默无动作 |
| 设备卡“读本章知识” | 跳 `chapter.html?id=<stage>` | 可用 | 正常 |
| `ask.html` | 库内命中直接答；库外走 `/api/ask` | 库内可用；服务不可用时显示“暂时没有找到…” | 未区分“无答案”和“服务不可用” |
| `write.html` | `/api/gen`；三体裁 + 事实底稿 | 显示原始 JSON 解析错误 | 无预置稿/可理解降级 |
| 写作结果 | 生成后可复制/下载/引用检索 | 依赖代理 | 未把结果回写沙盘或知识库 |

**闭环结论**：目前没有一条“设备操作 → AI 带到设备+操作 → 生成作品”的完整可用链路；设备级上下文只在 `__sceneContext` 数据结构层面存在，沙盘 UI 断在 AI 面板挂载。

## 6. 交互缺口汇总

### P0

1. 沙盘 AI 面板运行时异常（`ai.js:104`），`device-ask` 静默失效。
2. 三相分离器没有内部剖切/出口选择；不满足“设备内部世界”的标志性体验。
3. 塔“全剖”视觉上与半剖几乎相同，不满足验收底线第 9 条。

### P1

1. 五个关卡都在独立关卡场景/相机内，关卡结束后没有把“操作结果”留在总览设备上；闭环停在结果提示。
2. 设备层只有观察，没有结构探索/过程演示/操作实验；13 个设备能力高度同质。
3. 塔页无设备级上下文；分离器/储罐/加热炉没有剖切或内部演示。
4. `write.html` 无 API 降级不可读；`ask.html` 无服务时提示不区分原因。

### 已有但可复用

- 五关的状态写回、错误反馈、退出清理都是真实实现，可作为后续“过程演示”的模板；
- `__sceneContext` 字段（scene/stage/object/knowledge/mode/interaction/history）已存在，适合扩展为 AI 和跨页上下文；
- 塔页的 54 个命名对象、半剖壳和热点锚点是可复用的资产基础。
