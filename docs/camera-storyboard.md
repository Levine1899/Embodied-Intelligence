# Phase 02 · 镜头与声音脚本

日期：2026-11-22
适用：`sandbox.html` 的导览/追踪模式、塔页剖面页。所有镜头为**设计规格**，阶段 03–07 实现；不要求本阶段改代码。

## 1. 镜头语言总则

- 主镜头保持 **35–42° 视场**，接近人眼；不使用夸张广角。
- 运动以**低速度、长停留**为主；每个镜头至少 1.2s 静止观察，避免“飞过去”。
- 转场只用三种：`dolly`（推/拉）、`crane`（升降）、`orbit`（绕行 ≤ 25°）；不做旋转 360° 炫技。
- 用户任何 `pointerdown`/`wheel`/`touchstart` 立即暂停自动镜头，交还控制；界面显示“已接管”。
- `prefers-reduced-motion`：所有 800ms 以上运动改为瞬时/150ms 淡入，导览不自动播放。
- 镜头不穿过实体；地下剖面从南侧开口进入，不从岩体穿模。
- 每个章节结束必须停在**可继续操作**的画面：当前设备在画面 1/3 处，下一段路线可见。

## 3. 四个标志性体验的镜头分镜

### 分镜 1：地下穿越

1. **0–2s**：全景低角度，地表边缘占画面下 1/3；批次牌在井口旁。
2. **2–5s**：镜头下降，地表从画面顶部退出，地层剖面从左侧进入；雾从 `#0b0f11` 过渡到岩层暖褐。
3. **5–8s**：贴近储层；油点缓慢聚集，不是喷射；批次牌贴在岩芯上。
4. **8–12s**：用户拖动压力滑块；镜头保持，看到油向井筒方向移动；停留 2s。
5. **12–15s**：沿井筒上升到井口；井口阀组轻微动作；切到地面处理区远景。
6. **退出**：用户可点“回到全景”；镜头 crane out 1.8s，批次章保留。

### 分镜 2：管线追踪

1. **0–2s**：井口近景，管线向右延伸；批次牌沿管线低空移动。
2. **2–5s**：跟随镜头（低空 dolly），管线由井口到分离器入口；沿途只出现一个方向箭头。
3. **5–8s**：分离器侧 45°；切面打开 1.2s；气/油/水三条路径由细线连接，不铺满屏幕。
4. **8–11s**：用户选气出口“回收/火炬”；镜头分别给 1.5s 局部特写，再回到分离器。
5. **11–14s**：油出口管线转向储罐；镜头拉远，罐区进入画面。
6. **退出**：选“进入储运”或“返回分离器”；返回不重置已选路径。

### 分镜 3：蒸馏塔展开

1. **0–2s**：炼化高地远景，塔群剪影；逆光/边缘光，不闪烁。
2. **2–5s**：推到常压塔中段；进料管、侧线、平台依次出现，标签最多 3 个。
3. **5–7s**：半剖；镜头绕 15°，切面朝向用户；塔板/降液管可见。
4. **7–10s**：全剖；镜头拉近 1m 并升高 0.5m；塔板、降液管、侧线抽出全部可见；汽相上行/液相下行粒子分别运动。
5. **10–14s**：用户选“交通燃料/化工原料”；侧线高亮，管线向不同方向延伸；停留 2s 解释。
6. **退出**：切回外观时 600ms 合壳；保留选择记录；返回沙盘时批次章保留。

### 分镜 4：能源到生活

1. **0–2s**：塔顶/侧线，产品管线向城市方向下降；场景从清晨冷调过渡到日光暖调。
2. **2–5s**：低空跟随管线，城市街区、加油站、材料台依次出现。
3. **5–9s**：产品台近景；用户把馏分/产品拖到对应应用；正确配对出现“交付”章，错误配对弹回并给一句原因。
4. **9–12s**：用户选“燃料优先/材料优先”；城市灯光/材料应用权重变化，不显示数字。
5. **12–15s**：拉回全景；路线全链低亮，批次牌盖最后一章；出现回顾入口。
6. **退出**：回顾/自由探索/看塔/问 AI；不强制生成作品。

## 4. 声音设计（可选增强，默认关闭）

| 层 | 内容 | 触发 | 默认 | 失败策略 |
|---|---|---|---|---|
| 环境底噪 | 地下低频、地面风、厂区机械、城市远景 | 进入章节 | 关闭（总开关） | 静默，不影响任务 |
| 设备提示 | 泵/阀/塔板轻响，音量低于环境 | 选中/操作 | 随总开关 | 静默 |
| 交互确认 | 批次盖章、正确/错误反馈 | 任务动作 | 随总开关 | 视觉反馈始终存在 |
| AI 语音 | 可选朗读当前讲解 | 用户点“朗读” | 关闭 | 不阻塞文字 |

- 声音不是完成任务的条件；没有声音也能完成全部任务。
- 合成音必须标注“氛围示意，非现场录音”，不模拟真实声级。
- 音量控制：总开关 + 0–100 滑块；记忆在 session，不写 LocalStorage 敏感数据。
- 自动播放策略：首次用户交互后才创建 `AudioContext`；`prefers-reduced-motion` 不自动开声音。

## 5. 用户接管与异常

| 情况 | 行为 |
|---|---|
| 用户拖动/滚轮 | 立即暂停自动镜头，显示“已接管 · 继续导览”按钮；不弹窗 |
| 用户点“跳过” | 直接到下一章起始锚点，不播放过场 |
| 窗口失焦/页面隐藏 | 暂停镜头 tween、暂停关卡 loop；恢复时从当前机位继续 |
| WebGL 上下文丢失 | 停止镜头；显示 fallback；恢复后回到最近锚点，不继续原 tween |
| 低帧率 | tween 按真实 delta 推进；不跳帧瞬移；必要时降低粒子数 |
| 用户中途退出 | 批次章/选择保留在 session；再次进入从当前节点继续，不重置 |
