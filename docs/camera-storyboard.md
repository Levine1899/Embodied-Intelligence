# Phase 02 · 镜头与声音脚本（返修版）

日期：2026-11-22
适用：`sandbox.html` 的导览/任务/自由模式、塔页剖面页。本文件是设计规格，不是已实现镜头。
本版修正审查核心主题四、P2 镜头 FOV/声音范围；三个 Hero Moments 各补六帧分镜。

## 1. 镜头语言总则

- 主镜头使用 **Three.js `PerspectiveCamera` 垂直 FOV 40°**（若引擎按水平 FOV 配置，需换算并记录；阶段 03 统一用垂直 FOV 字段）。
- 运动以低速度、长停留为主；每镜至少 1.2s 静止观察。
- 转场只用 `dolly`（推/拉）、`crane`（升降）、`orbit`（≤25°）；不做 360° 旋转炫技。
- 用户 `pointerdown`/`wheel`/`touchstart` 立即暂停自动镜头并交还控制；不自动抢回。
- `prefers-reduced-motion`：800ms 以上运动改瞬时/150ms 淡入；导览不自动播放。
- 镜头不穿实体；地下剖面从南侧开口进入。
- 每镜结束停在可继续操作的画面：当前设备在画面 1/3 处，下一段路线可见。

## 2. 统一镜头规格字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `shotId` | 是 | 稳定 ID，如 `shot_hm1_kf3` |
| `purpose` | 是 | 这一镜让用户发现/理解什么 |
| `from` | 是 | 相机起始锚点 `cam_*` 或坐标 |
| `to` | 是 | 相机目标锚点 |
| `lookAt` | 是 | 注视目标（对象/锚点） |
| `fov` | 是 | 垂直 FOV，默认 40° |
| `moveType` | 是 | dolly/crane/orbit/rise/descend/follow |
| `duration/easing` | 是 | 毫秒 + 缓动；停留时长另列 |
| `sceneAction` | 是 | 镜头过程中的设备/结构/流线变化 |
| `narration` | 是 | 同步讲解/字幕要点 |
| `userControl` | 是 | 暂停/跳过/接管/退出 |
| `completion` | 是 | 镜头结束后允许的操作 |
| `fallback` | 是 | 缺资产/低性能时的降级 |

## 3. 章节镜头表

| shotId | 章节 | from → to | 运动 | 时长/停留 | 场景动作 | 完成/接管 |
|---|---|---|---|---|---|---|
| `shot_overview` | 全景 | `cam_vista` → 前推 2m | dolly | 3–4s / 1.5s | 批次牌/路线淡入 | 拖动接管 |
| `shot_descend` | 地下 | `cam_vista` → `cam_subsurface` | crane+descend | 3.5–4.5s / 2s | 地表退场、层理揭示 | 拖动/滚轮 |
| `shot_lift` | 井筒 | `cam_subsurface` → `cam_wellhead` | rise | 3–4s / 1.5s | 套管/水泥环、抽油机 | 拖动 |
| `shot_separate` | 分离 | `cam_wellhead` → `cam_separator` | dolly+orbit 15° | 3–4s / 2s | 切面打开、三出口 | 拖动 |
| `shot_store` | 储运 | `cam_separator` → `cam_tank` | crane+orbit 20° | 3.5–4.5s / 2s | 浮盘/油气空间 | 拖动 |
| `shot_refine` | 炼化 | `cam_tank` → `cam_tower` | rise+dolly | 4–5s / 2.5s | 半剖→全剖可切 | 拖动 |
| `shot_city` | 城市 | `cam_tower` → `cam_city` | dolly+orbit 12° | 3.5–4.5s / 2s | 日光、交付箱 | 拖动 |
| `shot_return` | 回顾 | `cam_city` → `cam_vista` | crane out | 2.5–3.5s / 2s | 路线/五章低亮 | 可跳过 |

锚点为设计规格，阶段 03 用实际场景坐标校准；命名统一 `cam_*`，不把坐标散落在多个文件。

## 4. 三个 Hero Moments 的六帧分镜

### HM-1 打开地下世界

| 帧 | 画面/镜头 | 主体 | 场景状态 | UI/操作 |
|---|---|---|---|---|
| KF1 进入前全景 | 低角度全景，地表边缘占下 1/3；地下剖面未打开 | 批次牌、井口剪影 | 批次牌在岩芯外侧，路线未亮 | 底部“接收批次”；接触环 |
| KF2 接近目标 | 下降到剖面开口，地表退出画面 | 岩层/井筒 | 层理逐层显现 | 地块标签最多 1 个 |
| KF3 结构揭示 | 侧 45° 贴近储层—井筒连接 | 储层透镜、井筒 | 储层高亮，油点在孔隙；盖层可见 | “放大储层”提示 |
| KF4 用户操作 | 保持中近景，滑块在画面下缘 | 压差滑块、井筒 | 油向井底粒子加速；批次牌沿井筒外侧上升 | 滑块“压差驱动示意（非真实压力值）” |
| KF5 结果反馈 | 略微升高，看到井筒到井口 | 井口、抽油机 | 牌到井口，第一枚章；路线延伸 | 盖章动效/短文案 |
| KF6 交还控制 | 拉到能同时看井口与集输区 | 井口/集输远景 | 地下剖面留下方 | “进入地面/返回全景”；自由旋转 |

- 完成：切换地层 ≥1、放大储层 ≥1、控制值 ≥90。
- 退出/重置：回全景；压差回 0，保留知识。
- 降级：无地下 Hero 时，以剖面台阶 + 2D 地质示意替代，标注“占位”，视觉验收 BLOCKED。

### HM-2 亲自完成三相分离

| 帧 | 画面/镜头 | 主体 | 场景状态 | UI/操作 |
|---|---|---|---|---|
| KF1 进入前全景 | 井口到分离器的低空视角 | 管线、分离器 | 批次牌沿管线外侧；三条路径未分 | “追踪管线” |
| KF2 接近目标 | 低空跟随管线到分离器进口 | 进口/鞍座 | 泵撬启动；管线有流向 | 可拖动接管 |
| KF3 结构揭示 | 侧 45°，切面打开 | 壳体/挡板/堰板/三出口 | 半剖或全剖；内部显现 | “剖开/合上” |
| KF4 用户操作 | 三出口近景，气口在上 | 气/油/水出口 | 启动分离；三相路径分开 | 选气去向；点油/水终点 |
| KF5 结果反馈 | 分别给气网/火炬 1.5s，再回分离器 | 气网/火炬/储罐/水处理 | 回收或火炬不同；油入罐；水到处理 | 路径高亮、错误回流 |
| KF6 交还控制 | 拉到集输—储运衔接 | 分离器/罐区 | 批次牌到罐区外侧 | “进入储运/返回”；自由查看 |

- 完成：气有去向 + 油入罐 + 水到处理。
- 退出/重置：合上分离器，清空分流；保留章。
- 降级：无内部结构时只允许外观+路径选择，内部验收 BLOCKED。

### HM-3 让蒸馏塔打开

| 帧 | 画面/镜头 | 主体 | 场景状态 | UI/操作 |
|---|---|---|---|---|
| KF1 进入前全景 | 炼化高地远景，塔群剪影 | 塔群/加热炉 | 逆光/边缘光，火炬受控 | “进入炼化” |
| KF2 接近目标 | 推到常压塔中段 | 进料/侧线/平台 | 进料高亮，批次牌在进料线外侧 | 可拖动 |
| KF3 结构揭示 | 绕塔侧 45°，半剖 | 半壳/塔板/降液管 | 半壳移开，塔板可见 | “半剖/全剖” |
| KF4 用户操作 | 全剖，略近略高 | 塔板/降液管/侧线/汽液粒子 | 全壳隐藏，汽相上行/液相下行 | 拖馏分到塔位 |
| KF5 结果反馈 | 侧线拉出到下游管线 | 侧线/产品管线 | 不同重点不同管线；正确/错误反馈 | 选燃料/材料 |
| KF6 交还控制 | 拉到塔体+城市远景 | 塔/城市 | 批次牌到产品线外侧 | “进入城市/看塔页/返回” |

- 完成：五种馏分全对 + 全剖 ≥1 次 + 选一个重点。
- 退出/重置：切回外观，清空馏分；保留选择。
- 硬验收：全剖 vs 半剖必须有结构级差异（塔板/降液管/侧线/粒子），不能只切换粒子。

## 5. 用户接管与异常

| 情况 | 行为 |
|---|---|
| 拖动/滚轮 | 暂停自动镜头，显示“已接管 · 继续导览”；不弹窗 |
| 跳过 | 到下一章起始锚点，不播放过场 |
| 页面隐藏/失焦 | 暂停 tween 与关卡 loop；恢复从当前机位继续 |
| WebGL 丢失 | 停止镜头；fallback；恢复回最近锚点，不继续原 tween |
| 低帧率 | 按真实 delta 推进；不跳帧瞬移；降粒子 |
| 中途退出 | 批次章/选择保留；再次进入从当前节点继续 |

## 6. 塔页镜头

| 状态 | 目标 | 距离 | 仰角 | FOV | 时长 |
|---|---|---|---|---|---|
| 外观 | 塔体 y≈11.5 | 33 | 0.26 | 40° | 1.2s |
| 半剖 | 塔体 y≈11.5 | 23 | 0.16 | 40° | 1.0s |
| 全剖 | 塔体 y≈11.5 | 21 | 0.20 | 40° | 1.0s |
| 热点 | 热点锚点 | 16–20 | 0.12–0.22 | 40° | 0.8–1.2s |
| 重置 | 外观锚点 | 33 | 0.26 | 40° | 1.0s |

全剖必须比半剖更近/更高，且内部结构真正可见；不能同机位只切粒子。

## 7. 声音

| 层 | 内容 | 触发 | 默认 | 失败策略 |
|---|---|---|---|---|
| 环境底噪 | 地下低频/地面风/厂区机械/城市远景 | 进章节 | 关闭（总开关） | 静默，不阻塞 |
| 设备提示 | 泵/阀/塔板轻响 | 选中/操作 | 随总开关 | 静默 |
| 交互确认 | 盖章/正确/错误 | 任务动作 | 随总开关 | 视觉反馈始终存在 |
| AI 语音 | 朗读当前讲解 | 用户点“朗读” | 关闭 | 不阻塞文字 |

- 声音不是完成条件；无音频资产/无 API 时体验完整。
- 合成音标注“氛围示意，非现场录音”，不模拟真实声级。
- 音量 0–100 + 总静音；首次交互后创建 AudioContext；`prefers-reduced-motion` 不自动开声音。
- **本期范围**：环境音/设备提示/交互确认可做；AI 语音列为可选，未实现时不得标“已完成”。

## 8. 验收

- 三个 Hero Moments 均有六帧分镜和完整镜头字段；
- 镜头关联锚点、任务步骤、设备对象，不是抽象“聚焦设备”；
- 用户接管后不被自动镜头抢回；
- 暂停/跳过/退出能恢复相机与设备状态；
- 塔页全剖/半剖有结构级差异；
- 无资产/低性能有 fallback，且明确标注降级。
