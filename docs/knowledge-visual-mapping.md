# Phase 02 · 科学知识与视觉表达映射

日期：2026-11-22
用途：把“要讲的原理”与“场景里看见的东西”一一对应，防止视觉奇观覆盖科学边界。阶段 03–06 实现、阶段 08 AI 上下文、阶段 09 审校共用此表。

## 总原则

- 颜色/线型只是教学编码，不等于真实物性；同一颜色在不同设备上不得表达相反含义。
- 所有动画是**教学示意**，不得称为真实 CFD、真实流场、工程仿真或数字孪生。
- 教学控制值只用于交互节奏，不是生产参数；不显示/不推算压力、温度、流量、产能、收率、排放量。
- 馏分是沸点范围切割的结果，不等于成品油；成品油还需调和/精制，部分化工品可能来自天然气、煤基或生物基。
- 所有设备内部结构以“教学可读”为目标，不宣称工程精度。

## 1. 地下地质与井筒

| 字段 | 内容 |
|---|---|
| knowledgeId | `kb_formation`、`kb_drill` |
| 科学原理 | 石油生成于烃源岩，运移后聚集在储层孔隙；盖层封闭；井筒连接储层与地面；压差/举升使流体向井底流动 |
| 真实对象/工艺 | 烃源岩、储层砂岩、盖层、套管、水泥环、射孔、采油树 |
| 教学简化 | 地层厚度与井深垂直夸张；储层用可见油点示意，不是真实孔隙尺度；一口井代表一类井，不是具体井 |
| 视觉表达 | 分层岩性带、储层透镜体、油点、井筒/套管/水泥环、井口阀组；压差滑块驱动油点向井底 |
| 禁止误导 | 不得画“地下油湖/油河”；不得把滑块 0–100 说成真实压力/采收率；不得暗示所有油都靠同一个压差采出 |
| 资料依据 | 阶段 01 知识库条目；后续由石油专业审校补充来源 |
| 反馈文案 | “油在岩石孔隙里。压差是驱动力之一；真实采收率还受储层和开发条件影响。” |

## 2. 三相分离器

| 字段 | 内容 |
|---|---|
| knowledgeId | `kb_gather` |
| 科学原理 | 井口产出物是油/气/水混合物；利用相态与密度差，在卧式分离器中分成气、油、水三路；出口结构与堰板/挡板控制液位与界面 |
| 真实对象/工艺 | 卧式分离器、进口挡板/分配器、油水堰板、气出口、油出口、水出口、压力/液位仪表、鞍座 |
| 教学简化 | 内部结构简化；不显示真实阀门开度/控制回路；不计算分离效率；气/油/水颜色只是编码 |
| 视觉表达 | 半剖/全剖显示挡板、堰板、三出口；三色路径分开；错误出口出现回流/原因；正确出口到达可见终点 |
| 禁止误导 | 不得说“过滤分开”；不得把火炬说成日常放空；不得给出排放量/效率数字；水处理必须有可见终点，不能只写在成功条件里 |
| 资料依据 | 阶段 01 知识库 `kb_gather`；公开油气集输科普资料 |
| 反馈文案 | “气最轻往上，油水按密度分层；分离器不是过滤器。” |

## 3. 储罐（固定顶 / 外浮顶）

| 字段 | 内容 |
|---|---|
| knowledgeId | `kb_store` |
| 科学原理 | 固定顶罐液位下降时油气空间变大；外浮顶罐浮盘随液位升降、贴近液面，减少油气空间；实际损耗仍受边缘密封、附件、操作与维护影响 |
| 真实对象/工艺 | 罐壁、固定顶/浮顶、浮盘、边缘密封、导向杆、呼吸阀、防火堤、进出罐管线 |
| 教学简化 | 只比较“油气空间”相对大小；不换算真实蒸发量/排放量；不模拟真实气象 |
| 视觉表达 | 液位滑块同时驱动两个罐；浮盘贴液面；固定顶罐气相空间增大；文字/图例同时标注 |
| 禁止误导 | 不得把“油气空间大”直接说成“排放量多少”；不得说固定顶罐不能用；不得给浮顶罐绝对“零损耗” |
| 资料依据 | 阶段 01 知识库 `kb_store`；公开储运科普资料 |
| 反馈文案 | “浮顶把油气空间压小，但损耗还取决于密封、附件和维护。” |

## 4. 常压/减压蒸馏塔

| 字段 | 内容 |
|---|---|
| knowledgeId | `kb_refine` |
| 科学原理 | 原油加热后进常压塔；塔板/填料使上升油气与下降回流液反复接触，按沸点范围在不同高度切出馏分；常压渣油可进减压塔，降低压力使重油在较低温度继续分离 |
| 真实对象/工艺 | 加热炉、常压塔、塔板/降液管、侧线、回流、塔顶气相、塔底渣油、减压塔、真空系统 |
| 教学简化 | 塔板数量/侧线位置为教学简化；不模拟真实塔板效率/回流比；不展示真实温度/压力分布；不给出收率 |
| 视觉表达 | 外观/半剖/全剖三态：半剖见半壳+塔板；全剖见塔板/降液管/侧线/汽液粒子；侧线高亮到下游 |
| 禁止误导 | 不得说常压塔直接产出“汽油/柴油成品”；不得把馏分等同于成品油；不得编造“一桶油出多少”；不得把全剖只做成粒子变化 |
| 资料依据 | 阶段 01 知识库 `kb_refine`；公开炼化科普资料 |
| 反馈文案 | “塔按沸点范围切馏分。馏分还要经过裂化、重整、加氢、精制与调和，才成为成品油。” |

## 5. 馏分与后续路线

| fractionId | 显示名 | 塔段/出口 | 后续路线（示意） | 不得表述 |
|---|---|---|---|---|
| `topgas` | 塔顶油气 | 塔顶气相 | 燃料气/轻烃回收，或安全泄放 | 不是“汽油成品” |
| `naphtha` | 石脑油馏分 | 上部侧线 | 重整/乙烯裂解/化工原料 | 不能直接说“塑料来自石脑油”单一路线 |
| `kerosene` | 煤油馏分 | 中部侧线 | 航空煤油/煤油调和 | 不是直接可用的航空煤油成品 |
| `diesel` | 柴油馏分 | 下部侧线 | 柴油调和/加氢精制 | 不是直接可用的车用柴油 |
| `residue` | 常压渣油 | 塔底 | 减压蒸馏/重质燃料/沥青原料 | 不是“废料” |

减压塔若展示，单独标注：减压馏分（如减压瓦斯油）与减压渣油；不复用常压塔的五个 fractionId。当前 l4 代码只把五个常压对象作为拖拽对象，阶段 06 若要增加减压对象必须先核验资产与代码，不得为凑数新增。

## 8. 反馈文案规则

1. 每个操作后先给“发生了什么”，再给“为什么”，最后给“边界”。
2. 不出现“真实压力/真实温度/实际产量/收率/排放量”的肯定句。
3. 错误反馈给原因，不给羞辱性文案；不扣分。
4. AI 上下文必须带 `knowledgeId` 和 `interaction`；回答沿用本表边界。
5. 儿童档用生活比喻，但不能改变事实；例如“塔像分层的筛子”可以，“油像水一样纯净”不可以。
