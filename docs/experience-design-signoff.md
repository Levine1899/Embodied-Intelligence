| 次要用户 | 普通成年公众；教师/展厅讲解员 |

## 2. 关键取舍

| 取舍 | 决定 | 理由 |
|---|---|---|
| 地下是否第一人称下潜 | 否，做剖面穿越 | 现有地下 Hero 不足，成本高；剖面仍能建立空间关系 |
| 是否重做成展馆群岛 | 否，保留连续沙盘 | 现有五关/13 设备/深链可复用；避免推翻 |
| 传播语“一滴油” | 不用 | 科学不准确；改用“教学示意批次” |
| 任务是否加积分/排名 | 不加 | 会退化成答题游戏；用批次章/路线/复盘 |
| 声音是否强制 | 不强制，默认关闭 | 无障碍与自动播放策略 |
| 是否本期适配手机 | 不承诺 | 与阶段 01 基线一致 |
| 是否改技术栈 | 否 | 原生 HTML/CSS/JS + Three r180 |
